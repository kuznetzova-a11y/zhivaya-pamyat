ЖИВАЯ ПАМЯТЬ — демонстрационный MVP сайта

Состав:
index.html — страницы сайта
styles.css — оформление
script.js — интерактивные сценарии
assets/ — утверждённые визуализации капсулы и парка

Запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере. Для загрузки фотографий деревьев и веб-шрифтов требуется интернет.
3. Для стабильной проверки QR-кода и всех возможностей лучше запустить локальный сервер:
   python -m http.server 8000
   Затем откройте http://localhost:8000

Что работает:
- горизонтальное листание каталога и раскрытие карточек;
- выбор капсулы: внешний вид / ранний разрез;
- выбор тарифа с переходом к форме;
- кликабельные участники минималистичного семейного древа;
- локальное редактирование истории выбранного человека;
- демонстрационная страница памяти;
- QR-код на раздел памяти (внешняя служба QR);
- демонстрационный личный кабинет;
- форма заявки с локальным сохранением в браузере;
- чат с готовыми ответами (не ИИ).

Ограничения:
Никакие реальные заявки не отправляются. Нет настоящей авторизации, серверной базы данных, оплаты или ИИ API.
Истории семей и контакты сохраняются в localStorage только этого браузера.
Имена и рассказы о родственниках — вымышленные.
Разрез капсулы показывает ранний концепт, не окончательную конструкцию. Материалы/биобезопасность требуют испытаний.
Фотографии деревьев загружаются с внешних ресурсов; некоторые являются иллюстративными природными видами, а не документированными изображениями указанного сорта. Для продакшена нужны проверенные лицензионные фотографии каждого вида и сорта.
